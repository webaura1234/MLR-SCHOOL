# Malla Reddy School

Official website for [Malla Reddy School, Medchal](https://www.mallareddyschool.com) — Next.js App Router.

## Scripts

```bash
npm install
npm run dev      # local dev at http://127.0.0.1:3000
npm run build    # production build + sitemap
npm run start    # serve production build
npm run lint
npm run sitemap  # regenerate public/sitemap.xml
```

## Notes

- Static sitemap lives at `public/sitemap.xml` (generated by `scripts/generate-sitemap.mjs`).
- After adding/removing `src/app/**/page.tsx` routes, run `npm run sitemap` and commit the updated sitemap.
